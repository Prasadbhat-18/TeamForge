# TaskForge

A production-quality MERN stack team project management app.

## Quick Start

1. Clone the repo
2. `cd server && npm install`  
3. Copy `server/.env.example` to `server/.env` and fill in your values
4. `cd client && npm install`  
5. Copy `client/.env.example` to `client/.env`  
6. `npm run seed` (from root)
7. `npm run dev` (from root)
